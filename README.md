# 电影分镜共创

面向 AI 视频的中文分镜共创技能。与作者逐镜讨论叙事意图、画面、动作、声音和切点，确认后逐步更新故事板。

## 核心能力

- 逐镜提问与推荐，保留待讨论与已确认状态。
- 将景别、构图、焦点、运镜、光线、剪辑与情绪落实到镜头设计。
- 采用精细黑白铅笔手绘分镜风格，导出自包含 HTML 故事板。
- 按空间复杂度决定是否需要场景调度图，多个镜头可共用场级图。
- 先根据草稿建立调度图，场景资产生成后重新校准物理锚点。
- 附带调度图 Python 工具、JSON 模板及参考图。

## 使用

将本仓库文件放入支持技能的助手的 `co-create-film-storyboards` 技能目录，入口是 [SKILL.md](SKILL.md)。

示例请求：

> 使用电影分镜共创，根据这个剧本和我逐镜讨论。先明确目标情绪，每次给出推荐并等我决定；边讨论边更新故事板。

图片与视频实际生成需要环境提供相应工具。本技能不绑定特定生成模型。调度图渲染依赖 Python、matplotlib 和 numpy，具体用法见 [工具说明](references/blocking-toolkit.md)。

## 文件

- `SKILL.md`：技能入口与协作规则。
- `references/`：电影语言、连续性、图像风格、导出与调度规则。
- `assets/`：故事板版式、铅笔风格参考与场景调度工具包。
- `scripts/render_blocking.py`：调度图渲染入口。

参考素材与工具包保留原内容；示例场景和坐标不代表当前项目的实际空间测量。
