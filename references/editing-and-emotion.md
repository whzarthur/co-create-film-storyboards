# 剪辑、转场与信息情绪

## 镜头组织

正反打不必逢台词切。先找信息影响谁，再选说者、听者、同框或细节。反应可用沉默、手停顿或身体变化，预留理解信息的过程。Coverage 在 AI 中是覆盖重要动作、决定、反应的素材组合，不默认生成所有景别保险素材。Cutaway 暂离主要动作补充语境；Insert 强调局部细节，功能可重叠。

## 切点

- 视线匹配：观看→对象；延迟揭示可制造悬念，但让作者决定何时知道。
- Eye Trace：相邻镜头关键注意点位置便于衔接，快速动作中减少重新定位。
- 动作中切：匹配动作阶段、方向、肢体和道具，避免重复或缺段。
- J-cut：下一镜声音先到；L-cut：上一镜声音延续。注明来源与出入点，实现方式另行规划。
- 交叉剪辑：交替事件线，常暗示同时；非同时需有线索避免错误因果。
- 理性蒙太奇：并置产生联想，不自动等于实际事件；新增隐喻画面先与作者确认。
- 长停留也可紧张，快切也可滑稽，不固定“长=悲伤、快=紧张”。

## 转场素材规划

| 手法 | 准备内容 |
|---|---|
| 直接切／突切 | 信息和反差，突切有明确惊吓、喜剧或情绪目的 |
| 淡入淡出 | 开始/结束/时间间隔及过渡时长，通常后期完成 |
| 叠化 | 可重叠画面、重叠时长及时间/情绪联系 |
| 匹配剪辑 | 对齐形状、主体位置、动作或方向，不只写无缝 |
| 圆形开合／划像 | 窗口中心或方向及作者确认的风格 |
| 遮挡转场 | 前镜遮满与后镜离开遮挡，颜色和运动可接 |
| 甩镜转场 | 前后方向、速度观感、模糊区和落点 |

可后期明确完成的转场，不强迫模型一次生成两处复杂场景。叠化重叠会影响总长，需计入。不为炫技加入转场。

## 作者讨论

“这句后留在说者脸上突出决绝，切到听者突出伤害，你想把情绪放在谁身上？”确认切点后检查下一镜起点。声音、转场或变速影响已确认时长时说明影响，不悄悄调整。
