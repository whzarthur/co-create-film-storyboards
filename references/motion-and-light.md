# 运镜、器材观感、速度与光

## 运动方式

| 方式 | 可见描述 |
|---|---|
| 固定 | 观察位置和朝向不变 |
| 水平摇／俯仰 | 位置不变，左右或上下转向 |
| 横移／升降 | 位置横向或垂直改变，不是转头 |
| 推进／拉远 | 靠近或远离，明确起止景别和背景变化 |
| 变焦／急变焦 | 固定位置缩放视野，急变焦强调突然关注 |
| 滑动变焦 | 主体大小近似不变，移动配反向变焦，背景显著变化 |
| 跟拍 | 明确从前/后/侧跟随的距离与终点 |
| 环绕 | 弧线方向、幅度、新显露的背景 |
| 滚转 | 绕光轴旋转，地平线倾斜或翻转 |
| 甩镜 | 快速转向产生模糊，明确出发和落点 |
| 不规则运动 | 明确轻微呼吸晃动或剧烈失衡，不泛写手持感 |

说明为何开始、揭示什么、何时停。组合运动需可解释轨迹且有表达价值。

## 器材转为观感

三脚架→稳定观察；移动摄影车→平滑位移；稳定器→流畅穿行；摇臂→升降与弧线揭示；身体固定→人物相对稳定、背景随身体剧烈变化；载具固定→保持与车辆的相对位置；无人机→空中路线与尺度；水下→水中位置、漂浮、折射和能见度。

运动控制不因写进 AI 提示词就保证精确重复，重复镜头需参考与路径约束并实测。顶拍是视角，防护壳无需出现在画面。无需提供器材采购或操作清单。

## 速度与帧率

分别记录动作表现速度、生成帧率（如支持）、成片帧率、后期变速。高帧率不等于慢动作，放入低帧率时间线也不必自动慢放，24 FPS 不是电影感保证。

慢动作说明要延长哪一瞬间；速度渐变写正常→慢→恢复的触发。抽动、拖影、加速不同，分别描述。只有实际逐帧重新解释播放时，才使用播放帧率/源帧率的速度比；不把实拍参数当模型可用设置。

## 光线

描述来源、方向、软硬、反差、颜色与变化。画内灯可解释主光来源，动机光无需画内可见。人物走动会合理改变受光，不将一致性写成所有位置亮度不变。

- 高调常为明亮低反差，低调保留阴影与强反差；情绪含义依语境。
- 软硬是阴影边缘等性质，不等于明暗。黄金时刻不必然软，要指定需要的阴影。
- 选择窗侧光、背光剪影、近镜侧或远镜侧面光时，明确要显露多少脸部信息。
- 冷暖受白平衡与环境影响，色温数字可辅助，不把日光永远写成蓝色。
- 斑驳光、遮挡阴影、轮廓、焦外光斑、镜头光晕分别描述，避免喧宾夺主。
- 不默认填写流明、照度、ISO、F/T 值和灯架，不承诺物理参数控制。平方反比衰减有适用条件，不拿它强推 AI 亮度。

## 讨论入口

“靠近她是为了看清表情，还是要让背景突然不安？”帮助选择推进或滑动变焦。“现在认出来人，还是先见轮廓？”帮助选择光线。“慢下来最值得看清什么？”帮助决定是否变速。每轮只问当前关键选择。
