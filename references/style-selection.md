# 分镜默认画风、主动覆盖与锁定

主分镜图默认使用技能自带铅笔样图的视觉风格，现成参考见 `../assets/storyboard-pencil-reference.png`。作者没有提出画风要求时直接登记并实际引用该样图，不询问是否切换，不因等待画风确认而阻塞正式主图。默认风格由参考图本身定义，不附加“黑白石墨铅笔”等媒介硬约束。作者主动指定其他风格、提供其他参考图或要求比较时，才进入覆盖流程。当前生效的画风贯穿后续镜头，除非作者明确要求变更。

## 选择流程

1. 先检查作者是否给出画风名称、参考图或明确的成片视觉方向。没有时直接读取 pencil-style.md，登记默认画风并继续，不提出画风问题。
2. 作者明确指定其他风格或提供其他参考图时，查看实际参考，区分其中的画风特征与人物、场景、构图内容；指令足够明确时直接建立覆盖画风锁定，只有缺少会实质改变结果的信息时才询问。
3. 作者主动要求切换但没有明确方向、表示不确定或希望比较时，根据题材、情绪、受众、人物表演需求和后续 AI 视频用途推荐 2–4 个有实质差异的方向。每个方向说明观众感受、适合之处和制作取舍，给出一个明确推荐；不要一次罗列全部风格史。
4. 切换候选必须配可见参考图。优先使用作者提供或项目已有且确实可访问的图片；没有合适图片时，用同一段项目内容、同一构图、同一人物状态生成一张多方案对比板或数张小样，使差异主要来自画风。图片中不要烧录容易出错的方案名称，用消息或 HTML 标签标注 A/B/C。不得只列影片名、艺术家名或文字形容词冒充图片参考。
5. 参考小样只用于选择画风，不视为正式分镜，不替作者决定尚未确认的剧情、人物造型或镜头处理。若首镜内容还没确定，使用不泄露剧情的中性测试构图；各方案必须保持相同主体、机位、光线意图和画幅，才能公平比较。
6. 作者选定覆盖风格后更新“画风锁定”。后续镜头不重复询问画风，但每镜都传入或引用当前生效的画风参考，并检查漂移。

## 推荐方向池

按项目选择少量候选，不把下表整批抛给作者：

| 家族 | 可选方向 | 常见效果与适用判断 |
|---|---|---|
| 传统手绘 | 写实石墨、墨线、赛璐璐、水彩、逐帧转描感 | 强调表演与手工痕迹；线条、色彩和背景精度决定可读性 |
| 立体材质 | 3D CGI、黏土定格感、剪纸纸偶、皮影或沙画质感 | 空间和材质鲜明；角色可动性、表情范围与制作一致性需评估 |
| 图形语言 | 扁平动态图形、像素、低多边形、极简线稿 | 信息读取快、风格统一；细腻表演和真实空间可能被简化 |
| 当代美学 | 霓虹复古、蒸汽波、厚涂绘本、复古印刷 | 氛围与识别度强；需防止色彩或纹理盖过叙事重点 |

这些是描述空间，不是固定套餐。推荐应写成可生成的视觉特征，不要求精确模仿某部作品或某位创作者。

## 画风锁定记录

至少记录以下实际会影响生成的项目：

- 画风名称与来源状态：自动默认或作者明确指定。
- 参考图片文件、版本或可访问标识；选中对比板中的哪一项。
- 媒介与技法：铅笔、水彩、平涂、三维材质、拼贴等。
- 彩色策略：黑白／有限色／全彩，以及主色、饱和度和明度关系。
- 线条与边缘：有无描边、粗细、硬软、规整或手绘波动。
- 质感与渲染：纸纹、颗粒、笔触、材质、真实度和细节密度。
- 人物与背景：比例、面部精度、背景完成度和透视处理。
- 光线与对比：明暗层次、阴影硬度、氛围和允许的特效。
- 禁止漂移：后续镜头不得自行改变的风格特征。

画风参考只约束呈现方式，不自动成为人物身份、服装、场景、道具或构图参考。生成后续镜头时分别传递画风参考、人物参考、场景参考和当前镜头构图／状态；工具仅支持少量图片时，说明取舍和风险，不能宣称全部约束都已传入。

## 变更与检查

作者要求换画风时，说明影响范围，提供新的参考图并重新确认画风锁定。明确是从某场、某镜开始变化，还是回改全部已确认镜头；不得静默混用。生成后对照画风参考检查媒介、色彩、线条、纹理、人物比例、背景完成度和光线对比，同时按 continuity.md 检查人物与状态。内容正确不能抵消明显画风漂移。

技能自带铅笔样图是自动生效的默认画风基准，其使用规则见 [pencil-style.md](pencil-style.md)。
