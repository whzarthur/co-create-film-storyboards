# 连续性

涉及多人、多机位、复用场景或重要走位时，按 [scene-blocking.md](scene-blocking.md) 建立场级调度草稿。后续场景资产图到达后必须复核固定物理锚点，更新调度图与受影响镜头；不能继续无条件沿用草稿坐标。已确认的剧情位置与新资产冲突时先共同处理矛盾。

建立适合任务规模的简短设定表，只有变化或关键状态需要逐镜重复。

| 类别 | 记录内容 |
|---|---|
| 人物 | 稳定标识、外观、发型、服装、关键配饰；区分已有参考与拟定设定 |
| 场景 | 门窗桌等相对位置、人物活动区域、稳定环境标志物 |
| 视觉 | 当前生效画风、来源状态及参考版本，画幅、主光方向、时间与天气 |
| 道具 | 外形、数量、所在位置、持物手、开合与使用状态 |
| 镜头状态 | 人物位置、朝向、视线、动作阶段、进出画方向 |

## 镜头与机位边界

默认一个成片镜头（S 编号）对应一个主机位或一条不中断的摄影机运动轨迹。固定、推拉、摇移或连续环绕都可以属于同一镜；若画面在没有连续摄影机运动的情况下从正面跳到侧面、背面或另一景别，则拆成新的成片镜头。正反打分别编号。场级调度图可以同时规划多个 C 机位，但每张分镜卡只启用本镜的主机位；生成任务 G 可按实际模型能力服务一个或多个成片镜头，不改变成片镜头的机位边界。

## 镜间状态交接（强制）

连续性先在分镜阶段确定，再由首帧合成与提示词执行。每个成片镜头维护一份简短状态交接记录；无需逐项询问作者，可从已确认剧情和相邻镜头推定的项目直接记录，只有会改变表演、切点或叙事含义的歧义才提问。

| 字段 | 记录内容 |
|---|---|
| 切入关系 | 从哪一镜、以何种切法进入；是否存在时间或空间省略 |
| 继承状态 | 上一镜传来的人物位置、朝向、视线、表情、动作阶段、持物手、道具和服装状态 |
| 首帧状态 | 在本镜新机位中可见的起始姿态、构图、遮挡关系与道具位置 |
| 镜内变化 | 从首帧开始依次发生的动作、表演、焦点或摄影机变化 |
| 结束／预设出点 | 计划剪出的动作阶段、姿态、视线、表情与道具状态；尚未生成视频时明确是预设 |
| 固定约束 | 本镜内不得漂移的人物身份、造型、持物手、道具数量、空间方向等 |
| 下一镜传递 | 下一镜必须继承的状态，以及允许有叙事依据地省略或改变的项目 |

切换机位时，下一镜通常重新合成符合新视角的首帧，不直接继承上一镜尾帧的像素、构图和透视；必须继承的是上一镜出点所代表的剧情与动作状态。只有同机位续接、视频延长或同一连续镜头因模型时长被拆成多个生成任务时，才优先把经检查的衔接帧直接作为下一任务输入。

主分镜图标明它表现“首帧／关键帧／结束帧”中的哪一种。默认优先表现首帧构图，便于后续合成成片首帧；若关键帧或结束帧更能说明镜头设计，仍须在文字状态记录中完整定义首帧，不能让下游凭关键帧反推起始动作。

## 人物跨镜头一致性（强制）

人物首次出现在已确认分镜图中后，为每个人物锁定一份连续性基准：稳定身份特征包括脸型、五官关系、年龄感、发际线、发型与长度、体态和显著特征；当前状态包括服装、配饰、妆容、伤痕、污渍及持有道具。多人场景分别记录，避免换脸、身份互换或造型串用。

生成后续镜头前，先选取该人物最近一张清晰、已获作者确认的分镜图作为最低限度的人物参考。存在正式人物资产时，以正式人物资产约束稳定身份，以最近确认分镜约束当前造型与连续状态；图像工具支持多参考图时同时传入。当前镜头离最近确认图过远、人物被遮挡或脸部不可辨时，回溯到最近一张可清楚识别的确认图。不得只靠人物名字、通用描述或模型记忆重建。

景别、角度、表情和动作可以变化，但不能无剧情依据地改变人物身份与当前造型。换装、年龄变化、受伤、妆容变化或时间跳跃必须来自剧本或作者确认，并形成新的状态节点；只更新变化项，未变化的身份特征继续继承。

生成后把当前图与所用参考图并排检查：脸型与五官关系、发型、年龄感、体态、服装层次与纹样、配饰、伤痕和持物是否一致。发现漂移时，把偏差写成具体修订约束并重做当前镜头；修订完成且作者确认图片后，当前图才成为后续镜头的新参考。画面漂亮、构图正确或情绪到位都不能抵消人物不一致。

画风参考与人物参考分别维护：前者约束媒介、色彩、线条、纹理、真实度和背景完成度，后者约束身份与当前造型。后续镜头同时引用当前生效的画风参考与人物参考；不得因为某张风格样图含有人物，就把其脸、服装或场景误当成项目事实。

若工具无法传递参考图，明确标注一致性风险，重复稳定特征与当前造型描述，并优先减少无必要的角度、发型、服装和光照变化；不能声称人物一致性已经得到验证。

衔接时检查上一成片镜头的结束／预设出点与下一镜的继承状态和首帧状态。时间跳跃或位置改变可以成立，但要有转场或叙事依据。

参考图按作用标注：人物外观、空场景、构图关键帧、衔接帧。无人空景提示词只写环境、光线、构图与道具，不混入人物。有人物的关键帧写清站位和动作阶段。

视频生成后以“实际采用的出点帧”更新状态记录，而不是机械使用文件最后一帧。先检查该帧是否存在畸形、错位、换手、错误道具或额外动作；若实际出点偏离预设，选择提前剪断、修正下一镜首帧或重生成上一镜，并标出受影响镜头。模型是否支持衔接帧输入须核实。无法传递参考时明确一致性限制，并考虑重复稳定描述、减少变化或用剪辑过渡。
