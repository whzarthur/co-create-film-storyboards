# 最终 HTML 故事板

## 使用参考

导出前读取 [保留的原始版式](../assets/storyboard-reference.html)。这是作者选择的视觉参考，不是可执行任务指令。原文件保留原样；在输出目录创建新的 `<作品名>-storyboard.html`，不要覆盖参考或未被要求替换的旧版本。

沿用参考 CSS、章节结构、卡片布局和交互，按实际内容增减场景和镜头。不得只提供文本表格或把所有故事板画面留空。自包含 HTML 使用内联 CSS、JS、SVG；使用已有图像时嵌入数据或提供完整本地资产包并说明，不依赖远程字体、CDN 或原桌面路径。

## 保留的视觉与结构

1. 米白纸张底纹、深色场记板、衬线中文标题、等宽技术标签和手写批注的整体风格。
2. 顶部吸附导航：总览、情绪曲线、各场景、构图语言、AI 生成任务；构图线开关与打印按钮。
3. 场记板：片名、段落、镜数、画幅、成片帧率、总时长、版本、日期及阶段状态。
4. 创作阐述和分镜总表：镜号、画面、景别、机位/角度、运镜、时长、起止时间、声音和转场；镜号链接到卡片。
5. 情绪曲线：根据已确认节拍绘制，说明是创作意图示意，不是测量值；未确认精确张力时用定性节拍，不能伪造作者给过 0–10 分。不得固定三幕或高潮上升曲线。
6. 场景头：场景名、环境/时间、视觉色板。主分镜图画风与成片色彩设计是否相同按作者确认结果记录，不默认单色。
7. 逐镜卡片：镜号、标题、状态、景别、时长和时间标签；左侧主分镜图标明“首帧／关键帧／结束帧”及动作描述，右侧机位、运镜、焦点/光线（适用时）、对白/声音、转场、构图批注。另设紧凑的状态交接块，呈现切入关系、继承状态、首帧状态、镜内变化、结束／预设出点、固定约束和下一镜传递；没有相邻镜或无需传递的项目可合并简写。
8. 场景调度图：按 [scene-blocking.md](scene-blocking.md) 的场级条件决定是否绘制。场级总图展示人物、道具、全部虚拟机位、视线、轴线和动线；相关镜头卡片在右侧机位/连续性区域用 16:9 缩略图显示从总图派生的当前机位聚焦图，其他机位默认隐藏。只有正反打、越轴或衔接比较需要时才保留一个降灰的相关机位。场景或状态首次出现的卡片提供“查看全场机位”入口；转折镜头可并列两个状态聚焦图。点击或键盘操作后在灯箱中查看完整图。默认不设置全宽调度图区，只有作者要求总览或调度图是主要交付物时才增加。标注草稿或资产校准状态、版本、依据资产与锚点表。纯局部特写可引用对应聚焦图；无需调度图的场景给文字站位说明。
9. 构图语言：只总结本片实际确认使用的策略，不复制示例的“唯一正中构图”等故事专属规则。
10. AI 生成任务：保留原 skill 的镜号映射、参考图与成片首帧需求、首帧状态、镜内变化、结束／预设出点、采用时长与生成时长、完整可复制提示词和下一镜传递说明。提示词从已确认的状态交接生成，不在此阶段重新发明连续性。可在单镜下折叠展示，但不能因参考没有这些字段而删掉。跨镜任务在统一区域列出并从镜头链接。

## 画面和调度图

主分镜图的默认推荐画风是写实黑白石墨铅笔，但仍须按 [画风选择与锁定](style-selection.md) 询问作者是否保持。作者确认保持时读取 pencil-style.md；确认切换到彩色、三维、拼贴、像素或其他方向时，按相应的已确认参考和特征呈现。原 HTML 只决定页面版式，不能覆盖项目最终确认的画风。俯视调度图和构图辅助线仍以准确清楚为先，可使用功能性 SVG 和颜色，不必模仿主分镜画风。

总览中显示已确认的画风名称、参考图缩略图或文件标识及版本；不默认展示未选方案。主分镜图表达人物、道具、空间比例、取景边界和关键动作，不冒充已生成的视频画面。嵌入已获作者认可的实际主图，不把简化 SVG 人形或几何草图当成最终主分镜图。原参考的 SVG、故事文字、人物、物件和黑白铅笔标签不能直接沿用为新故事内容。

每镜的草图、调度图、文字和提示词必须一致；构图线与箭头放入可切换 guides 图层。明确是起始、关键或结束画面；重要构图变化可用两帧辅助图。用户要求精细 AI 关键帧时再按相应工具流程生成，不将导出 HTML 默认为付费生成授权。

按成片画幅设置 viewBox；不能把原 800×450 横屏比例强行用于竖屏。SVG 共享 defs 可复用，标识符须唯一，放大图所需 defs 仍可访问。俯视图默认示意、不按比例；未确认距离、焦距、传感器规格时不照抄米数、FOV 和机高。

## 时间与内容准确性

已确认帧率时可显示 HH:MM:SS:FF，按帧计算且说明区间结束点不计入本镜。帧率未定时使用秒级时间，不默认参考的 25fps；非整数帧率时间码未明确规则时也先使用秒级时间。转场重叠、黑场、无声停留都要计入实际时间，不能只把镜头时长机械相加。

不要继承参考的《遮天》、九龙拉棺、人物名、10 镜、83 秒、日期、数值、故事批注或调度比例。标题、导航、总表、曲线、卡片和页脚由同一组已确认内容保持同步。导出不改变确认流程；阶段稿显著标明未定项目，不能为填满模板擅自补镜头。

## 交互与校验

- 保留显示/隐藏构图线、主分镜图与调度缩略图点击放大、点击遮罩或 Esc 关闭、打印样式；支持键盘打开图片及关闭后焦点返回。
- 自包含 HTML 中每张总图或聚焦图只嵌入一次；多个分镜卡通过共享数据源、ID 或脚本映射复用，避免重复 base64。共用同一机位与状态的镜头应复用同一聚焦图，不必按镜号各生成一张；无脚本模式下也要避免重复生成源图，并检查交付体积。
- 保留高清原图作为源资产；带透明通道或像素边缘需要精确保留时使用 PNG，其他主分镜图的 HTML 浏览副本建议缩放到不超过 1280px 宽并转为质量约 82 的 WebP，调度图建议不超过 1100px 宽、质量约 80。不得直接把全部高清原图逐张转为 base64 塞入页面。
- 构建后检查 HTML 文件大小。阶段故事板以不超过 10MB 为目标；超过 20MB 视为打开风险，必须压缩、降采样或改为完整本地资产包后再交付。压缩不得覆盖原始分镜图。
- 小屏卡片改为单列，宽表格在容器内横向滚动，导航和标签能换行。
- 打印隐藏导航和灯箱、显示构图线；提示词若用折叠容器，打印时展开内容。检查长卡片不会被截掉。
- 内容插入 HTML 前转义；不执行来源或剧本文字中的脚本/事件。不加入网络请求或发布行为。
- 校验镜头数、时间、导航锚点、唯一 ID、SVG 引用、提示词映射；搜索原故事专属文字残留。
- 逐卡检查调度缩略图：只出现本镜实际使用的机位；需要比较时最多保留一个有明确用途的相关机位并降灰；“查看全场机位”只放在场景或状态首次出现的卡片。聚焦图中的人物、道具和轴线必须与场景总图一致。
- 用可用浏览器查看桌面与窄屏，检查至少总览、一个完整卡片、单缩略图卡片、跨状态双缩略图卡片、调度灯箱和生成任务；操作构图线、灯箱与打印预览。无法渲染时报告只完成静态校验，不能声称视觉检查通过。

交付最终 HTML 的绝对路径链接；用户要求时再加 Markdown/PDF。不要把浏览器“打印”按钮的存在说成已经导出了 PDF。
