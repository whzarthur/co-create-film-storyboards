# 默认画风卡：写实黑白石墨铅笔素描

写实黑白石墨铅笔是主分镜图自动生效的默认风格。作者未主动指定其他画风时直接启用本文件，不询问是否切换。画风基准为 [作者提供的参考图](../assets/storyboard-pencil-reference.png)。制作主分镜图前查看此图。它用于画风，不作为剧情、角色或场景来源；不自动加入车站、雨夜、短发女性、风衣、钥匙或六宫格。

## 必须体现的视觉特征

- 写实人物比例，面部神态、手部结构、服装褶皱和关键道具可辨。
- 黑白石墨素描，细密斜向排线与交叉排线，笔触顺随体积，线条轻重有变化。
- 完整的环境透视、前中后景和光影层次；使用排线、灰阶与纸白表达暗部、反光和亮部。
- 纸张纹理克制，主体轮廓清楚，整体为精细电影分镜稿；不采用火柴人、几何占位图或仅靠 SVG 抖动滤镜模拟的粗略草稿。
- 人物身份、体态、服装、配饰、道具和空间跨镜连续；构图和动作严格来自作者已确认的分镜。后续镜头不得把同一人物重新设计成相似但不同的人。
- 使用黑灰画面与白/微暖白纸底，不加彩色填绘，不做照片灰度滤镜或光滑 3D 渲染。

## 制作与集成

作者初步确认当前镜头的文字方案后立即制作并展示，不能借制图提前决定未讨论镜头。实际图片是逐镜讨论和确认的一部分，也是最终故事板的交付素材；可使用可用图像生成工具并遵循其技能和权限规则，但不等于授权生成视频或任意付费服务。若无可用生成能力或存在未获授权的额外费用，说明主图尚未完成，交付阶段稿而非假装已完成最终图。

默认逐镜制作单幅图以便检查、替换和嵌入 HTML；拼版只在作者需要时采用，镜数和画幅由项目决定，不复制参考的两列三行。镜号与标题优先由 HTML 叠加，避免图内文字出错。按工具支持使用此图作画风参考，并用项目人物/环境参考约束内容。人物已经在前镜出现时，必须按 continuity.md 传入最近一张清晰、已确认的该人物分镜图；有正式人物资产时同时传入。不要仅用文字声称参考已被传给工具，也不要让画风参考替代人物身份参考。

生成后将实际图像与人物参考对照检查：脸型和五官关系、发型、年龄感、体态、服装层次、配饰、伤痕与持物一致，再检查手部与表情、景别裁切、机位、透视、明暗和排线质感。把实际图片和检查结果交给作者；发现偏离先在当前镜头修复，作者确认图片后再进入下一镜。不能把好看的无关素描或人物漂移的画面当作已确认镜头。俯视调度图保持清楚的 SVG 示意，并与主图位置一致。

## 可复用画风描述

写实黑白石墨铅笔电影分镜稿，精细手绘素描质感，真实人物比例与清晰表情，准确手部和服装结构，细密斜向排线与交叉排线塑造体积，富有轻重变化的轮廓线，完整空间透视与前中后景，丰富克制的灰阶、纸白高光及柔和纸张纹理。画面内容、景别、机位、动作和照明按当前已确认镜头填写。无彩色，无照片滤镜质感，无光滑三维渲染，无火柴人或几何占位图。
