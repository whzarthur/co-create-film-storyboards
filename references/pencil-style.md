# 默认画风卡：技能自带铅笔样图

作者未主动指定其他画风时，主分镜图直接使用 [技能自带铅笔样图](../assets/storyboard-pencil-reference.png) 作为视觉风格参考，不询问是否切换。制作主分镜图前必须查看并在图像工具支持时实际传入该文件。

样图本身是风格基准。不要再用“黑白石墨铅笔”“必须写实”“必须交叉排线”“禁止彩色”等文字标签建立第二套硬约束，也不要因为文字描述与样图存在差异而覆盖样图。生成与检查时对照样图实际可见的线条组织、明暗关系、画面质感、人物刻画程度、环境完成度和分镜可读性。

样图只负责画风，不作为剧情、角色、场景、道具、构图或拼版数量的来源；不得自动加入车站、雨夜、短发女性、风衣、钥匙或六宫格。人物身份、体态、服装、配饰、道具和空间仍按项目资产、已确认分镜与 continuity.md 继承，构图和动作严格来自作者已确认的当前镜头。

## 制作与集成

作者初步确认当前镜头的文字方案后立即制作并展示，不能借制图提前决定未讨论镜头。实际图片是逐镜讨论和确认的一部分，也是最终故事板的交付素材；可使用可用图像生成工具并遵循其技能和权限规则，但不等于授权生成视频或任意付费服务。若无可用生成能力或存在未获授权的额外费用，说明主图尚未完成，交付阶段稿而非假装已完成最终图。

默认逐镜制作单幅图以便检查、替换和嵌入 HTML；拼版只在作者需要时采用，镜数和画幅由项目决定，不复制参考的两列三行。镜号与标题优先由 HTML 叠加，避免图内文字出错。按工具支持使用此图作画风参考，并用项目人物/环境参考约束内容。人物已经在前镜出现时，必须按 continuity.md 传入最近一张清晰、已确认的该人物分镜图；有正式人物资产时同时传入。不要仅用文字声称参考已被传给工具，也不要让画风参考替代人物身份参考。

生成后将实际图像与人物参考对照检查：脸型和五官关系、发型、年龄感、体态、服装层次、配饰、伤痕与持物一致，再检查手部与表情、景别裁切、机位、透视，以及与自带样图的可见风格一致性。主分镜图的验收重点是构图、站位、空间方向和动作关系；先把能够表达这些信息的第一张图交给作者。若只是剧本中的局部颜色、材质或光效没有体现在图上，保留图并在镜头说明中注明成片意图，不自行再生成近似图。影响分镜判断、人物身份或连续性的偏离才先在当前镜头修复；作者明确要求图上呈现非关键细节时，优先考虑保持其他像素与构图的局部编辑。作者确认图片后再进入下一镜。不能把画风相近但内容错误或人物漂移的画面当作已确认镜头。俯视调度图保持清楚的 SVG 示意，并与主图位置一致。

## 工具不能传图时

只有图像工具确实不能接收参考图时，才根据刚刚查看的样图写一段简短的视觉描述作为降级方案。描述样图当前可见的表现，不把铅笔媒介名称、黑白属性或某种排线技法写成必须满足的固定清单，并明确记录本次没有实际传入风格参考图。

该样图只规定故事板图的呈现；不要自动把它的视觉风格写进最终视频提示词，除非作者也指定视频采用同一画风。
