# 景别、构图、视角与焦点

## 分清维度

景别是范围；单人/双人/过肩是人物组织；POV 是观看立场；机位高度是观察位置；俯仰是朝向；建立镜头/主镜头/插入镜头是功能。它们可组合，不是同一组互斥标签。

| 选择 | 可见内容与用途 |
|---|---|
| 远景 | 人物在环境中较小；保留环境压力、规模和距离 |
| 全景 | 头脚完整；呈现全身姿态和行动路线 |
| 牛仔镜头 | 大腿附近以上；保留手、腰部道具和蓄势动作 |
| 中景 | 大致腰部以上；兼顾表情、手部和环境 |
| 中近景 | 大致胸部以上；减少环境干扰，保留身体反应 |
| 特写／大特写 | 面部或局部；让微小反应或线索可辨 |
| 建立镜头 | 建立地点、时间、关系或气氛；不必是远景或航拍 |
| 主镜头 | 组织整场动作和空间的基础视角；AI 不必生成整场作为保险 |

以具体裁切描述补足名称差异。不固定使用“远景→中景→特写”的顺序。

单人可聚焦个人；双人/多人同框保留同时发生的关系和反应。Dirty Single/过肩保留他人局部存在；干净单人减少这种联系。过肩不自动等于严格 POV，POV 必须符合观看者实际位置。插入镜头强调必须看清的道具、动作或细节。

## 高度与角度

眼平、肩、腰、膝、地面机位不自动等于俯仰；腰部高度也能水平观察手部。俯拍可交代空间，仰拍可强化体量，但强弱意义依情境。顶拍强调布局；荷兰角是画面倾斜，不是机位高度。

## 构图组织

先定第一注意点、视线路线、最终落点，再选择：

- 点与引导线：孤立主体、走廊、栏杆、人物注视指向信息。
- 形状和框中框：门窗、镜子、三角站位组织关系；封闭框可能压迫也可能保护。
- 纹理与图案：对比使主体突出，相似使主体融合；打破重复形成异常线索。
- 正负空间：为视线、移动或潜在威胁留空间；故意挤压应有表达依据。
- 前中后景：各层承载可读信息，避免全都抢注意力。
- 平衡/对称/三分/黄金比例都是可选方法；不按几何规则评分，不为奇数原则增删人物。
- 色彩与明暗可压过形状的影响。控制背景视觉重量，不给颜色套固定善恶含义。
- 按最终画幅组织构图，横屏裁竖屏后需重新检查位置关系和留白。

## 清晰区域

| 手法 | 提示词应描述 |
|---|---|
| 深焦 | 前中后景哪些对象同时清楚，为什么需要并行信息 |
| 浅景深 | 谁清晰、什么虚化，背景信息是否仍需可辨 |
| 柔焦 | 整体柔和朦胧的质感，不等于浅景深 |
| 转焦 | A 清晰/B 模糊→A 模糊/B 清晰，触发动作与时间 |
| 分焦效果 | 两个相距较远区域同时清晰，中间可模糊，不等于深焦 |
| 移轴/倾斜焦平面 | 局部清晰带及虚化位置；微缩感只是可选用途 |

转焦不是运镜。技术效果失败时先与作者讨论切镜替代，不能自行改变揭示顺序。

## 镜头空间观感

广角配近距离可夸张前后尺度，标准视角减少夸张，长焦配远观察位置可使前后景看似更靠近；透视由观察位置决定，不能说只变焦距就改变透视。鱼眼弯曲直线区别于普通超广角。微距强调纹理和微小动作。焦段分类依成像规格而变，笔记的数字不是通用界限或 AI 物理保证。

## 作者讨论入口

按需要选一个：“这里要同时看到双方反应，还是只盯着她？”“门口的人一开始就清楚，还是回头时才转焦显露？”“观众要贴近他，还是隔着环境观察？”给出有理由的推荐，不一口气问遍。确认后落实为构图、机位和清晰对象。
