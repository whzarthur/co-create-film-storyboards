# 生成规划与修复

## 映射规则

为成片镜头用 S01 等编号，为生成任务用 G01 等编号；每个任务列出服务的镜头。记录生成目标时长和成片采用时长，前者以模型实际支持为准。保留剪辑余量时说明用途，不强制固定秒数。

先识别动作复杂度：多人交互、换手、遮挡后再出现、穿门、快速转身、大幅绕拍和多物体接触会提高连续性难度。优先围绕一个主要事件组织片段；评估后再拆分，不设通用硬上限。

复杂镜头的替代应保留关键因果。例如难以稳定生成完整开门动作时，可用手部细节、人物反应和门外镜头连接；若剧情核心正是开门手法，则不能省略。

## 首帧与状态交接

先读取 continuity.md 中已确认的镜间状态交接记录，再组装生成任务。提示词负责执行已经确定的连续性，不能用文字补救与继承状态矛盾的首帧。

- 黑白铅笔主分镜图用于表达构图、机位、调度与表演意图，不默认充当最终成片风格图像。需要首帧生视频时，结合正式人物、场景、道具资产和已校准调度图，合成符合本镜新机位与“首帧状态”的成片关键帧。
- 切换机位后，为下一成片镜头重新合成首帧；上一镜传递的是实际采用出点的动作与剧情状态，不是原尾帧的透视和像素。同机位续接、延长或同一连续镜头拆任务时才考虑直接传递合格衔接帧。
- 首帧必须先通过人物身份、造型、站位、持物手、道具状态、视线、动作阶段和场景锚点检查。首帧错误时先修图，不依赖视频提示词在运动中纠正。
- 尚未生成上一镜视频时使用“预设出点”规划下一镜；有实际素材后改用“实际采用的出点”，并在偏差影响下一镜时更新首帧或剪辑方案。

## 提示词

每个可单独提交的提示词包含必要的稳定设定，避免只写“同上”。结构可用：

> 画幅与风格；所用首帧及其已确认状态；从首帧开始按时间顺序发生的可见动作；主要镜头运动；结束／预设出点状态；光线；对白/声音需求；固定约束与下一镜传递要求。

不要把情绪词作为唯一表演指令。不要堆叠相互冲突的风格和运镜。需要模型专用语法时核实后适配；不支持负面提示词的模型不要强塞独立负面字段。

对白、口型、字幕、配音和环境声分别规划。没有确认原生音频支持时，将声音标为后期制作需求，不暗示已能直接生成。

## 检查实际结果

检查故事信息是否表达、人物与环境是否一致、动作是否合理、时长是否够用、实际采用的入点与出点是否符合状态交接、对白是否正确。不要把视频文件最后一帧自动当成出点；以实际剪辑采用位置为准。实际视频无法读取时向用户索取问题描述或可用媒体，不虚构检查结果。

修复记录：问题位置 → 可观察问题 → 推测原因（如有）→ 最小改动 → 需重生成的任务 → 受影响的相邻衔接。优先局部修复并检查邻接镜头；不因一处失败无差别重生成全部。实际调用可能产生费用时遵循用户已授权范围，不自动无限重试。
